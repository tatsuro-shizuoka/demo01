Concept

     

       

         

目の前の畑から、世界の価値観をやわらかく。

         

            デモ用のコピーです。里山の小さな畑から始まる「心うごく」ストーリーを、

            まるでエッセイを読むようなリズムで伝えられるセクションをイメージしています。

         

         

           

諦めたり、傷ついたり、いっぱいいっぱいだったり。

           

それでも、この土地で種をまき、土を耕し、

           

自分たちらしいペースで、暮らしと農業を続けていく。

           

固くなってしまった心や価値観を、そっとほぐしていくように。

         

       


       

         

           

              Our Mission

           

           

Women farmers with soft power.

           

              このカードには、コンセプトの要約や、短い英語コピーなどを入れておくと、

              海外向けの説明にもそのまま使えます。

           


           

             

                01 / Support

                子育てと農業の両立など、女性農家ならではの課題に寄り添う。

             

             

                02 / Community

                ひとりで頑張りすぎないためのコミュニティと学びの場をつくる。

             

             

                03 / Product

                こころをほぐすおいしさを、商品や体験として届ける。

             

           

         

       

     


     

     

       

Values

       

         

           

Value 1

           

soft mind

           

女性農家の「心」をやわらかく。

           

              「頑張りすぎてしまう」人が、自分を犠牲にせずに続けられる農業のあり方をいっしょに考える場。

           

         

         

           

Value 2

           

soft view

           

「こうあるべき」をやわらかく。

           

              規模や年数ではなく、自分の暮らしにしっくりくるスタイルを尊重し合う文化を育てます。

           

         

         

           

Value 3

           

soft table

           

食卓から世界をやわらかく。

           

              雑味のない、しみこむような味わいを通して、忙しい日常に小さな余白を届けます。
